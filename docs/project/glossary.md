# Glossário

| Termo | Definição |
|---|---|
| Organização | Fronteira de tenancy e propriedade que contém projetos e memberships |
| Organização pessoal | Organização criada automaticamente para cada usuário no cadastro, sem modelo especial de propriedade |
| Membership organizacional | Relação que concede a um usuário um papel em uma organização |
| Projeto monitorado | Produto/repositório externo cujas atividades são acompanhadas pela EIP |
| Membership de projeto | Relação que concede a um usuário um papel em um projeto |
| Repositório | Ativo de código monitorado por um projeto |
| Fonte | Ferramenta ou sistema que origina evidências, como Git, Maven, CI ou agente de IA |
| ProjectSource | Vínculo e configuração de uma fonte em um projeto |
| Coletor | Software ou integração que extrai e transmite dados; não é a identidade autorizada |
| Identidade de serviço | Principal não humano de um coletor, escopado a um projeto, fontes e permissões concedidas |
| Credencial de serviço | Segredo opaco associado a uma identidade de serviço, armazenado somente como hash |
| Evento de auditoria | Registro de segurança e administração separado de fatos de domínio e logs operacionais |
| Evento | Registro imutável de algo ocorrido em determinado instante |
| Atividade | Unidade de trabalho de engenharia com objetivo identificável |
| Sessão | Intervalo de trabalho ou execução relacionado a uma atividade |
| Execução de IA | Uso de um modelo/agente para realizar uma tarefa ou parte dela |
| Trace | Conjunto correlacionado de operações de uma execução |
| Span | Operação individual dentro de um trace |
| Evidência | Dado observado ou derivado, com origem e método conhecidos |
| Contexto | Informação documental que explica intenção, decisão ou circunstância |
| Insight | Interpretação produzida a partir de evidências e contexto |
| Recomendação | Ação sugerida, com justificativa, limitações e confiança |
| Proveniência | Registro da origem e transformação de um dado |
| Baseline | Referência histórica usada para comparação |
| Resultado observado | Consequência mensurada após uma decisão ou implementação |
